KANBAN OS TECNICOS VIP - PACOTE SOBE E RODA

Este pacote esta pronto para subir e rodar a ferramenta.

RODAR RAPIDO NO WINDOWS
1. Descompacte.
2. Coloque o token IXC em uma das opcoes:
   - arquivo: .openclaw/secrets/ixc_api_token.txt
   - variavel de ambiente: IXC_API_TOKEN
3. Execute: RODAR-WINDOWS.bat
4. Acesse: http://IP_DO_SERVIDOR:8765

RODAR RAPIDO NO LINUX
1. Descompacte em /opt/kanban-vip ou outra pasta.
2. Rode: chmod +x rodar-linux.sh
3. Coloque o token IXC em uma das opcoes:
   - arquivo: .openclaw/secrets/ixc_api_token.txt
   - variavel de ambiente: IXC_API_TOKEN
4. Execute: ./rodar-linux.sh
5. Acesse: http://IP_DO_SERVIDOR:8765

RODAR COM DOCKER
1. Copie .env.example para .env.
2. Preencha IXC_API_TOKEN no .env.
3. Execute: docker compose up -d --build
4. Acesse: http://IP_DO_SERVIDOR:8765
